Chaves de API

Ficam guardadas só neste navegador (localStorage), nunca em nenhum servidor. Qualquer pessoa com acesso físico a este aparelho e a este navegador pode vê-las — não use num dispositivo compartilhado.

Outros provedores

Adicione qualquer serviço compatível com o formato "OpenAI Chat Completions" (Mistral, Groq, DeepSeek, xAI/Grok, Together, Perplexity, etc.) — é o padrão que a maioria segue.

ChatGPT não está disponível nesta versão sem servidor — a OpenAI bloqueia chamadas diretas do navegador, com ou sem chave.
